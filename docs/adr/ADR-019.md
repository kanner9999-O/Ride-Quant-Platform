## 2. Decision

## 6. Consequences

**Tích cực:** trách nhiệm composition nằm ĐÚNG tại module ĐÃ sở hữu run identity — semantic cohesion cao, KHÔNG cần leak Backtest vocabulary vào Decision/Risk hay bất kỳ projection KHÔNG liên quan nào; CHỈ MỘT edge mới cần thiết (số lượng thay đổi registry nhỏ nhất trong ba candidate — hai edge tới decision-authority-service/risk-gateway ĐÃ tồn tại từ trước); KHÔNG reopen một package Consolidated Stable THỨ HAI ngoài Package 1.3-A (đã đang chạm qua §13a); cung cấp một premise ổn định cho Package 1.6's tương lai correction transaction VÀ cho api-architecture.md's parity-transcription update; tương thích trực tiếp với UC-006/007/010's Product-level behavior đã established (KHÔNG cần Product/UX correction nào đi kèm).

**Tiêu cực:** thêm một trách nhiệm (query composition) vào một module `runtime_service` vốn mô tả bằng ngôn ngữ orchestration — taxonomy tension nhẹ, cần Review A xác nhận liệu `hybrid` declaration có cần thiết; contract-category interaction gap (`consumes` thiếu `query`) sẽ tồn tại sau khi edge được áp dụng, đòi hỏi hoặc mở rộng field đó hoặc chấp nhận gap carry-forward tường minh (tiền lệ có sẵn nhưng vẫn một quyết định cần ghi nhận tại transaction alignment); backtest-orchestrator's orchestration load (khởi tạo run mới) VÀ composition load (trả lời truy vấn về run cũ) CÙNG một module — tiềm năng resource/availability coupling ở scale lớn (§5, flagged KHÔNG resolve).

**Thuộc phạm vi khác, KHÔNG thuộc ADR này:** field-level query/response schema; API path; storage/caching mechanism; concrete correlation/index implementation; `module-registry.yaml`/`system-decomposition.md`/`api-architecture.md` correction (transaction riêng, §7); Package 1.6 correction (transaction riêng, §9); `DD-001`; `backtest-orchestrator.owns_authoritative_state` cụ thể; `hybrid` taxonomy declaration cho backtest-orchestrator (nếu cần).
